# WF-088 - Auto-assign the correct price book or price list to a deal by rule

- **Domain:** Pricing, quoting and proposals (`quoting-proposals`)
- **Research source:** `docs/research/raw/quoting-proposals.md` section 3
- **Distinct sources cited:** 3
- **Branch:** `feature/WF-088-auto-assign-the-correct-price-book-or-price`

## Research evidence

- **name:** Auto-assign the correct price book or price list to a deal by rule
- **user_flow:**
  1. HubSpot: `CRM > Products` → **Manage price books** → open a price book → hover **Assignment rules** → click the **edit icon**.
  2. HubSpot: in **Filters** click **+ Add filter** → configure deal-property filters (`and` / `or` groups) → review the matching deals in the right panel → toggle **Auto-assigned** on → **Save** → toggle the price book's **Inactive** switch off to activate.
  3. HubSpot: three modes are chosen deliberately — *No assignment rules* (manual only), *Assignment rules without auto-assignment* (test first), *Assignment rules with auto-assignment*.
  4. HubSpot override: on the deal's *Line items* card click **Price book: None** (or the price book name) → **Price book** dropdown → **Change price book**. Changing the price book removes previously added line items.
  5. Dynamics 365 Sales: enable the Sales tab system setting (or set `Organization.UseInbuiltRuleForDefaultPriceSelectionRule = 1`), associate a price level with a **Territory** using the **Territory Default Pricelist** connection role, and assign the territory to the user. Single match → price level set automatically; multiple matches → the user must choose.
- **data_flow:** Deal/company property values (HubSpot) or the acting user's sales territory (Dynamics) → filter/condition evaluation → one matching price book / price level is written onto the deal/quote header (`pricelevelid` in Dynamics) at creation → the product lookup and line-item price resolution are then scoped to that book, so only that book's products/prices/terms are browsable when adding line items → the quote inherits the price book from the deal.
- **data_sources:** HubSpot deal properties, company properties, price book object. Dynamics `territory`, `pricelevel`, `systemuser`, `organization.UseInbuiltRuleForDefaultPriceSelectionRule`.
- **apis_hit:** HubSpot — properties API (`GET /crm/properties/...`), deal object `PATCH` for the price book association. Dynamics — **`GetDefaultPriceLevelRequest`** message ("Dynamics 365 internally uses the `GetDefaultPriceLevelRequest` message to determine the default price level"), registrable as a plug-in: "Register the plug-in on the `GetDefaultPriceLevel` message."
- **automations:** Auto-assignment runs when a deal row is created ("Price books are auto-assigned only when a deal is created. After a price book is auto-assigned, HubSpot won't run auto-assignment again if the deal or associated company properties used in the filter are updated"). Dynamics `GetDefaultPriceLevel` fires on create/update of opportunity/quote/order/invoice rows.
- **features_tools:** HubSpot price book assignment-rule editor, deal *Line items* card price-book selector, Super Admin override. Dynamics System Settings → Sales tab, territory form + **Territory Default Pricelist** connection role, plug-in registration on `GetDefaultPriceLevel`.
- **extensibility:** HubSpot — "if multiple price books match, the deal owner can choose which matching price book to use"; Super Admins can override; turning **off** the *Create custom line items* permission forces price-book-only behaviour. Dynamics — replace the built-in rule with a plug-in that returns your own price level.
- **sources:**
  - https://knowledge.hubspot.com/products/use-price-books
  - https://learn.microsoft.com/en-us/dynamics365/sales/developer/set-default-price-level-for-opportunity-quote-order-invoice
  - https://learn.microsoft.com/en-us/dynamics365/sales/create-edit-quote-sales
- **evidence:** "When a deal matches exactly one assignment rule, that price book is automatically assigned." · "If multiple price books match, the deal owner can choose which matching price book to use." · "Quotes inherit the price book from the associated deal. Users can't select a price book when creating a quote; they must select it on the deal." · "If the price book is changed, any line items associated with the previous price book will be removed." · Dynamics: "If a single price level is returned, the price level is automatically set … If multiple price levels are returned, the price level field isn't populated and the user must specify a price level."
