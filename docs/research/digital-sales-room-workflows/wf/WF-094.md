# WF-094 - Publish and share the quote as a hosted link or email

- **Domain:** Pricing, quoting and proposals (`quoting-proposals`)
- **Research source:** `docs/research/raw/quoting-proposals.md` section 9
- **Distinct sources cited:** 7
- **Branch:** `feature/WF-094-publish-and-share-the-quote-as-a-hosted`

## Research evidence

- **name:** Publish and share the quote as a hosted link or email
- **user_flow:**
  1. HubSpot: connect a domain (`Settings > Domains & URLs`); by default "quotes are hosted on the landing page primary domain connected to your account" and a separate subdomain (e.g. `billing.website.com`) can be used.
  2. HubSpot: in the quote editor top-right click **Share** (if no approval needed) → the quote moves to a *Shared* status "even if it hasn't been sent to the buyer."
  3. HubSpot: in the **Copy link, download PDF** tab click **Copy link** or **Download PDF** (live preview shown in the right panel).
  4. HubSpot: in the **Send quote email** tab — **To** auto-fills from the associated contact (changeable; a new email auto-creates a contact), **Cc** up to nine addresses, **From** defaults to the configured default from address, **Subject**, **Templates**, **Documents**, **Meetings** (scheduling page), body with formatting/personalisation tokens → **Send quote email**. The buyer receives the quote details, a link to view the quote in their browser, and a PDF attachment.
  5. HubSpot: from the quotes index page you can **Copy link**, **Download**, **Send by email**, or **Actions > Download published quotes** (a download link is emailed).
  6. Dynamics 365 Sales: open the quote → command bar **Export to PDF** → choose a Word template, set the **Save as** name → **Download**, or **Email** (the email form opens with fields prefilled and the PDF attached), or **Save to SharePoint** (default `SharePointDocumentLocation` = `<record_name>_<record_id>`) / **Save to Dynamics** (PDF stored as a note/attachment on the record). Mobile: **Create PDF** / **Email as PDF**.
- **data_flow:** Quote record + template + branding → rendered document → on publish the platform computes read-only properties `hs_quote_link` (public URL), `hs_domain`, `hs_slug`, `hs_locked=true`, `hs_pdf_download_link`, `hs_quote_number`, `hs_quote_amount`, `hs_language`, `hs_locale`, `hs_timezone` → a share/email event is created (tracking the recipient address) → the buyer receives an email carrying the link (and PDF if under 20 MB) and the quote becomes publicly viewable at the domain+slug URL. In Dynamics, the Word template merge produces a PDF that is then either downloaded, emailed, written to SharePoint's default document location, or attached as a note.
- **data_sources:** HubSpot quote object (`hs_quote_link`, `hs_domain`, `hs_slug`, `hs_pdf_download_link`, `hs_locked`), connected email/team email channel, HubSpot domains & URLs, Files tool. Dynamics `documenttemplate`, notes/attachments, `SharePointDocumentLocation` / SharePoint document library, Dynamics email.
- **apis_hit:** HubSpot — publish is state-driven on the quote object: `PATCH /crm/objects/{version}/quotes/{quoteId}`; `hs_quote_link` is "a read-only property and cannot be set through the API after publishing"; `hs_domain` and `hs_slug` are set by state. `GET crm/properties/{version}/quotes` returns the set. Dynamics — **Export to PDF** is a platform document-generation action (no public Web API endpoint documented on the pages read); SharePoint document location tables (`sharepointdocumentlocation`, `sharepointsite`) hold the output.
- **automations:** Publishing computes and freezes the totals: "The active quote state has the same price as the draft state. However, the overall amount is locked and can't be modified after it's published." Recurrence of automated reminders is configured in Settings → Objects → Quotes → **Reminders** tab (see workflow 14). Quote activity (`Quote published`, `Quote sent`) is logged automatically.
- **features_tools:** HubSpot **Share** button, **Copy link / download PDF** tab, **Send quote email** tab with live preview, **Send by email** action, **Actions** menu on the index page, domain/subdomain settings, default from address setting. Dynamics **Export to PDF** dialog with template selector and preview, **Email as PDF**, **Word Templates > Download/Upload Template**, SharePoint integration toggle + entity **Document Management** flag.
- **extensibility:** HubSpot — control the public surface via domain, `hs_slug`, password policy, identity verification, and locale/language; template source code and custom modules shape the document; branded PDFs are downloadable. Dynamics — new Word templates for any entity (`manage-word-templates`), custom file names, Save to SharePoint or Dynamics, accessible-PDF workflow (export to Word then Word's "Create PDF/XPS" with "Document structure tags for accessibility").

This is a read-only property and cannot be set through the API after publishing." · "`hs_locked` … Set to `true`. To modify any properties after you've published a quote, you must first update the `hs_status` of the quote back to `DRAFT`, `PENDING_APPROVAL`, or `REJECTED`." · Dynamics: "the generated PDF file is always saved to the default location: `<record_name>_<record_id>`"; "You'll see optimum performance when the file size is less than 2 MB."
