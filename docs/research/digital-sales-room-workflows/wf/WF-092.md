# WF-092 - Chain sequential multi-level approvals through a workflow

- **Domain:** Pricing, quoting and proposals (`quoting-proposals`)
- **Research source:** `docs/research/raw/quoting-proposals.md` section 7
- **Distinct sources cited:** 5
- **Branch:** `feature/WF-092-chain-sequential-multi-level-approvals-through-a-workflow`

## Research evidence

- **name:** Chain sequential multi-level approvals through a workflow
- **user_flow:**
  1. HubSpot (Super Admin, Revenue Hub Enterprise): `Settings` → `Objects` → **Quotes** → **Approvals** tab → **Approvals** on → toggle **Advanced quote approvals** on → click **Edit** to open the approval workflow.
  2. Under the trigger, click **+** → left panel **Branch** → select **One property or action output** → choose the **Quote amount** property → **Next** → set the branch condition (e.g. greater than 5,000) → **Save**. Optionally enable **Re-enroll** in **Settings**.
  3. Under the criteria branch click **+** → **CRM** section → **Add quote approval step** → **Message to approver** (can embed quote properties via *Choose data variable*) → **Approvers** dropdown → **Priority** (for sequential) → **Save**.
  4. Click **+** again → **CRM** → **Start quote approval flow** → under *Approvers required* select **All approvers**, **Any approvers**, or **Sequential** → **Save**.
  5. Under the **None met** branch add **Go to action** → **Start quote approval flow** (so non-qualifying quotes skip approvals) → **Done** → **Review and turn on**.
  6. NetSuite equivalent: `Customization > Workflow > Workflows` → **New** (Record Type `Transaction`, Sub Type `Estimate`, Release Status `Testing`, **Execute As Admin**) → **Initiation** = Event-Based, Trigger Type `All`, Contexts `Web Store`, **On Create** → condition via **Visual Builder** (`Total` greater than or equal to `3000.00`) → **Save** → then define states **Estimate Creation**, **Pending Approval**, **Approved**, **Rejected** with **Set Field Value**, **Add Button** (Approve / Reject) and **Send Email** actions and conditional transitions.
- **data_flow:** Quote properties and related-record properties (quote amount, discount level, SKU, billing frequency, net terms, user attributes, related deal) are read by the workflow's branch engine → each qualifying branch pushes an *approval step* (approver list + priority) onto the quote → `Start quote approval flow` executes the chain, sequentially or in parallel, writing intermediate state and notifying the active approver → the last decision writes `APPROVED`/`REJECTED` and the quote becomes publishable. In NetSuite, the estimate row's custom **Approval Status** field is stepped `Pending Approval → Approved | Rejected` and an email is sent to the sales rep, with automatic approval when the rep has no supervisor.
- **data_sources:** HubSpot quote/line-item/deal/user properties; the HubSpot workflows engine; HubSpot notifications (bell/email/Teams/Slack/Google Chat). NetSuite: Estimate/transaction record, employee record (supervisor), custom body field for approval status, workflow manager state machine, email.
- **apis_hit:** HubSpot — workflow configuration is created/edited in the workflows tool ("The approval workflow is created using the workflows tool when advanced workflows are turned on"); quote `hs_status` via `PATCH /crm/objects/{version}/quotes/{quoteId}`. NetSuite — `Customization > Workflow > Workflows` with `GetDefaultPriceLevel`-style message registration is the analogous extension model; the documented example uses the **Condition Builder** and the **Workflow Manager** workspace, plus the `OrderQuoteApproval` workflow states.
- **automations:** Fully rule-driven, no user action needed to route. Limits documented: "You can add up to five sequences, and ten approvers per sequence"; "Sequential approvals require approval by every approver at each priority step"; "if a quote approval step hasn't been added above this action, quotes will be auto-approved." Re-enrollment can be toggled for quotes that need re-approval after edits. Notifications fire automatically on each step.
- **features_tools:** HubSpot workflow editor with **Branch**, **Add quote approval step**, **Start quote approval flow**, **Re-enroll** switch, priority ordering; Breeze Assistant can author the workflow ("use AI"); **Approvals** sidebar panel; NetSuite **Workflow Manager** (states, actions, transitions), **Add Button** actions for the web store, **Set Field Value**, **Send Email**.
- **extensibility:** HubSpot — you may branch on "one property or action output", use multiple branches for different approval types, and must use the single generated approval workflow ("You can't duplicate the workflow or create a new workflow to use for quote approvals"); users with *Edit permissions for workflows* can maintain it after a Super Admin turns advanced approvals on. NetSuite — new **States**/**Actions**/**Transitions** are added in the Workflow Manager; workflow ownership + `Execute As Admin` gives the workflow access to employee records; conditional transitions are driven by employee supervisor data.

- **evidence:** "Use **sequential approvals** ranked by priority. You can add up to five sequences, and ten approvers per sequence. For example, you could set a sales manager as first priority, a sales director as second priority, and a legal representative as third priority. The sales director won't need to approve the quote until the sales manager has completed their approval." · "Set Branch 1 to greater than 5,000. This would be the start of an advanced approval workflow for any quotes above $5,000." · "**Start quote approval flow:** if a quote approval step hasn't been added above this action, quotes will be auto-approved." · NetSuite: "This workflow starts when a customer submits a new order quote over a set limit, in this case $3000. The system checks if the sales rep on the estimate has a supervisor." · "Estimate Creation State … Transitions to … **Approved** if the estimate shows a default sales rep and that sales rep has no supervisor on their employee record." · "Add Button: Add an **Approve** button / Add Button: Add a **Reject** button."
