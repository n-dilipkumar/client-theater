# WF-101 - Convert an accepted quote into an order and lock the price

## Research evidence

- **name:** Convert an accepted quote into an order and lock the price
- **user_flow:**
  1. Dynamics 365 Sales: `Quotes` → open the quote you want to convert → command bar **Activate Quote** (after acceptance "you won't be able to revise it").
  2. Click **Create Order** on the command bar (in Sales Professional this is only available if the admin has enabled creation of orders from quotes).
  3. In the **Create Order** dialog set **Date Won** (defaults to today) → add a description → **OK**. "The order is created and all products from the quote are added to the order. The price list and currency are also copied from the quote to the order."
  4. Check the **Prices Locked** field on the order: with sales order processing integration disabled it becomes **Yes**; with it enabled it takes the default from the `ispricelocked` column on the Order table (default **No** if unchanged).
  5. To change the behaviour later: on the order/invoice, command bar → **More Commands** → **Lock Pricing** (sets Prices Locked = Yes; Price Per Unit becomes non-editable; write-in products can no longer be added; changing the price list does not reprice existing lines) or **Use Current Pricing** (Prices Locked = No; Price Per Unit editable; prices auto-update to the price list when the record is opened or edited; overridden line prices are unaffected).
  6. The order is then fulfilled (closed as fulfilled) or cancelled; an invoice is created from the order. You can add products, change tax, and use **Get Products** from an opportunity on the order.
  7. API path: use the **`ConvertQuoteToSalesOrder`** message/action; a quote may also be **won** with `WinQuote` and closed with `CloseQuote` (Lost / Canceled / Revised).
- **data_flow:** Accepted + activated `Quote` row (+ its `QuoteDetail` lines) → `ConvertQuoteToSalesOrder` clones price list, currency, products, addresses, shipping and totals onto a new `salesorder` row (+ `salesorderdetail` lines) → `ispricelocked` is stamped on the order header → subsequent price-list edits either apply to the order (current pricing) or are ignored (locked) → `orderclose` records fulfilment, and `invoice` + `invoicedetail` are created for billing. The related opportunity can be kept open or closed; if closed, the final revenue amount is recorded.
- **data_sources:** Dataverse `quote` / `quotedetail`, `salesorder` / `salesorderdetail`, `orderclose`, `invoice` / `invoicedetail`, `pricelevel`, `pricelevelproduct`, `product`, `account`/`contact`, `customeraddress`, `opportunity` (optional close).
- **apis_hit:** Dynamics Web API / SDK for .NET: **`ConvertQuoteToSalesOrder`** (`ConvertQuoteToSalesOrderRequest`, "Event: False"), **`WinQuote`** (`WinQuoteRequest`, Event: True), **`CloseQuote`** (`CloseQuoteRequest`, Event: True), `WinOpportunity`, `Rollup`, plus `POST /salesorders`, `GET /salesorders`, `PATCH /salesorders({salesorderid})`; `RetrieveExchangeRate` for currency resolution.
- **automations:** "Depending on whether you've enabled sales order processing integration, the **Prices Locked** field is set as follows: If the integration is disabled, the **Prices Locked** field is set to **Yes**. If the integration is enabled … set to the default value specified for the `ispricelocked` column in the Order table." Under **Use Current Pricing**, "the price of the line items is automatically updated to reflect any changes in the price list" on open/edit. A quote is read-only once Active: "Activating a quote makes it read-only so your version matches the customer's version." Order/invoice cannot be updated once closed or fulfilled.
- **features_tools:** Quote command bar **Activate Quote** / **Create Order** / **Create Order** dialog with **Date Won**; order **Prices Locked** read-only field; **Lock Pricing** and **Use Current Pricing** commands under **More Commands**; order **Products** grid with inline price/qty/discount edits; **Get Products**; fulfilment/cancel; the `enable-creation-of-orders-from-quotes` and `enable-sales-order-processing-integration` org settings.
- **extensibility:** Whether the order locks price is a system-level default (`ispricelocked` on the Order table) plus a per-record toggle; sales order processing integration changes the default; write-in product prices are overridden so they are only addable when Prices Locked = No; a plug-in can be registered on `ConvertQuoteToSalesOrder`; Sales Professional feature gating is controlled by org settings.
