# WF-093 - Build a branded proposal from a template

- **Domain:** Pricing, quoting and proposals (`quoting-proposals`)
- **Research source:** `docs/research/raw/quoting-proposals.md` section 8
- **Distinct sources cited:** 7
- **Branch:** `feature/WF-093-build-a-branded-proposal-from-a-template`

## Research evidence

- **name:** Build a branded proposal from a template
- **user_flow:**
  1. HubSpot (Super Admin): `Settings` → **Branding** and/or `Settings` → `Objects` → **Quotes** → **Quote templates** tab → create a template. In the template editor configure each module: **header** (quote reference label, issue date, expiration date, currency label, PO number, logo), **parties** (seller, buyer, bill-to), **cover letter** / **executive summary**, **line items** (+ **Totals** tab), **terms**, **acceptance**.
  2. HubSpot: associate a **Brand** with the template (Enterprise); the brand appears top-right in the quote editor and drives logo/brand-kit colours; **Override brand kit** toggles and **Show company name when logo isn't set** control logo fallbacks. Logos can come from the quote branding settings, account branding, or the brand; images are chosen from the Files tool.
  3. HubSpot: hide/show sections with the view/hide icons; drag modules to reorder; in a rich-text section click **Advanced > Source code** to inject custom code.
  4. HubSpot: the template's cover letter / executive summary can be **generated by HubSpot's AI** "using data from line items, deal activities, meeting transcripts, notes, and emails."
  5. Dynamics 365 Sales: on any record, command bar → **Word Templates > Download Template** to get a Word file containing the entity's XML data → in Word enable the **Developer** tab → **XML Mapping Pane** → pick the schema starting `urn:microsoft-crm/document-template/` → right-click entity fields → **Insert Content Control > Plain Text** (Picture also allowed) → set repeating fields (**Repeating** on a table row) for 1:N data → save → **Word Templates > Upload Template**. Then on a quote: **Word Templates** → pick template to generate a populated Word document.
  6. PandaDoc: build a template in the editor containing a **pricing table**, **Content Placeholder (Smart Content)** blocks, fields, and approval-workflow configuration; content library items supply reusable terms/pricing/signature blocks.
- **data_flow:** Template definition (layout, module order, branding tokens, field bindings) + record data (deal, company, contacts, line items, quote fields) are merged at instantiation → either an HTML/JSON document model rendered by the HubSpot quote editor (and rasterised to PDF on publish) or a Word content-control/XML merge (Dynamics) → the resulting document is stored as the quote's presentation layer, with `hs_domain`/`hs_slug` deciding the public URL and the template id (`286` association) recorded on the quote.
- **data_sources:** HubSpot quote templates (`quote_templates`, `hs_type=cpq_template`), Brands, brand kit / account branding, Files tool, quote + deal + line item + contact + company records. Dynamics: document templates table, entity XML schema (`urn:microsoft-crm/document-template/`), `SharePointDocumentLocation`, Dynamics notes/attachments. PandaDoc templates, content library, pricing tables, folder hierarchy.
- **apis_hit:** HubSpot — `GET /crm/objects/{version}/quote_templates?properties=hs_type`; `POST /crm/objects/{version}/quote_templates/search` (filter `hs_type` CONTAINS_TOKEN `cpq_template`); quote↔template association type id `286` settable only at quote creation. PandaDoc — `POST /public/v1/documents` with `template_uuid`; `GET /public/v1/documents/{id}/details`; template management via `/public/v1/templates` (per `developers.pandadoc.com/llms.txt` index: create template, create from file upload, template details incl. `content_placeholders`, update tokens, share settings, folders).
- **automations:** AI module generation on template creation and on demand per module (Breeze icon). Template changes do **not** retro-apply: "Updating your logo and branding won't update existing published quotes, only currently drafted quotes and quotes created after updating."
- **features_tools:** HubSpot quote template builder, module editor, quote branding settings, Brands, **Customize quote style** action, **Advanced > Source code**, AI icon, desktop/mobile preview. Dynamics: Power Platform admin center → **Templates > Document templates**, Word Developer tab + XML Mapping Pane, security roles for **Document Template** vs **Personal Document Template**. PandaDoc template editor with Content Placeholder blocks, pricing table, `data_merge` column mapping.
- **extensibility:** HubSpot — **custom-coded modules** built with HubSpot CMS React/HubL (line-items table with sections, custom totals, billing schedule, ramps, conditional T&Cs by buyer country/product, custom parties section, custom nav menu, section-acknowledgment checkboxes); module source code editing; templates shareable; "API users can select templates that have custom modules included on them." Dynamics — full Word template control, `Repeating` content controls, entity relationships chosen at download, access controlled via security roles. PandaDoc — `content_placeholders` array replaces blocks with content library items at creation time (up to 10 items per placeholder), `data_merge: true` to use CRM-matching column names, `variables` in document titles.

The brand is set by the template used for the quote." · "The quote template's properties, content, and associations will be added to the quote as supplemental information, with properties set on the quote overriding the quote template's settings." · "It isn't possible to create or add custom coded modules to a quote using the API. API users can select templates that have custom modules included on them." · Dynamics: "Select the XML schema. It starts with `urn:microsoft-crm/document-template/`" and "you can only return up to 100 related records for each relationship." · PandaDoc: "Each content placeholder must be replaced with at least 1 content library item. You can add up to 10 content library items per content placeholder."
