## Research evidence

- **name:** Track buyer engagement on a shared quote and drive follow-up
- **user_flow:**
  1. HubSpot (Super Admin): `Settings` → **Objects** → **Quotes** → under *Analyze quote activity level tracking threshold* enter the **high activity threshold**. Published quotes below it are classified *Low activity*.
  2. Any time: `Revenue > Quotes` → **Actions > Analyze your published quotes** → use the **time period** dropdown to filter by expiration date → in the *Your published quotes* bubble chart, quotes below the threshold render black and above it green; hover for name, expiration date and activity count; tick **Show older expired quotes**.
  3. Under **Pipeline overview** read the value of high-activity quotes, quotes at risk of expiring, and the quote acceptance rate; under **Recent quote activity** see name/last activity/amount/expiration; under **Recommended follow-ups** act on suggestions (e.g. no activity in a long time, expiring soon) by clicking **Send a follow up** which opens the **Send quote** dialog.
  4. On the index page, read the **Last Activity Date**, **Activity Count**, **Activity Count Since Last Communication** and **View Count** columns; filter by **Status**, **Last activity date**, **Owner**, **Signing status**, or **Advanced filters**.
  5. Open a single quote → **Preview** → *Quote activities* card in the right sidebar; or **Actions > Activity** for the full timeline. Deal board views show a colour-coded quote status chip on each deal card.
  6. Report further via `Actions > Go to quote reports` (revenue analytics suite) or custom single-object reports on the quote object; export all published quotes (`Export` / `Actions > Download published quotes`).
- **data_flow:** Anonymous and authenticated buyer interactions with the hosted quote (page views, PDF downloads, prints, clicks-to-sign) plus internal seller/approver actions are written as timestamped activity records against the quote → counters (`Last Activity Date`, `Activity Count`, `Activity Count Since Last Communication`, `View Count`) are maintained → the count is compared to the configured high-activity threshold to colour-code the quote and to drive the expiration/engagement bubble chart → the chart and Recommended follow-ups list surface at-risk quotes → the seller re-sends the quote email from the recommendation, generating a new `Quote sent` activity and (if previously expired/recalled) a new send.
- **data_sources:** HubSpot quote activity log (buyer + seller events), quote object analytics columns, quote index views/segments, HubSpot revenue analytics suite reports, custom reports, connected email channel (for "since last communication"), sales workspace / deal board views.
- **apis_hit:** HubSpot — activity/analytics columns on `/crm/objects/{version}/quotes` (read via `GET`); quote reassignment activity "may be available through APIs depending on how the event is configured and the permissions of the API request"; reports and exports run through `import-and-export`; **Download published quotes** delivers a link by email.
- **automations:** Activity events are written server-side without user action. The seller activity list includes `Quote published`, `Quote approval requested`, `Quote approval rejected / requested changes`, `Quote approved`, `Quote recalled`, `Quote countersigned`, `Quote reassigned`, `Signing attempt failed`, `Chat started` (buyer started a chat with the closing agent) and `Quote expired`. Buyer events include `Quote sent`, `Quote viewed`, `Quote downloaded`, `Quote printed`, `Quote buyer signed`, `Quote manually signed`, `Quote accepted`. Quote activity can be used as a **workflow** enrolment condition, and draft quotes "can be enrolled in workflows".
- **features_tools:** *Analyze your published quotes* dashboard (bubble chart, Pipeline overview, Recent quote activity, Recommended follow-ups), *Quote activities* card, full Activity timeline, index-page view tabs (expiring soon / pending acceptance / pending approval), Advanced filters with saved views, revenue analytics suite, board-view status chips.
- **extensibility:** The activity threshold is configurable; custom quote properties can be added (`Actions > Edit properties`) and used in filters; quotes can be associated to **custom objects** (Enterprise) to fold quotes into a bespoke data model; reports can be built on the quote object; the same activity stream feeds workflows and the Claude connector / Agent CLI (betas).
