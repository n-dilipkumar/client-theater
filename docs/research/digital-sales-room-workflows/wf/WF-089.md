# WF-089 - Quote in a transaction currency with FX conversion and same-currency constraints

- **Domain:** Pricing, quoting and proposals (`quoting-proposals`)
- **Research source:** `docs/research/raw/quoting-proposals.md` section 4
- **Distinct sources cited:** 7
- **Branch:** `feature/WF-089-quote-in-a-transaction-currency-with-fx-conversion`

## Research evidence

- **name:** Quote in a transaction currency with FX conversion
- **user_flow:**
  1. Dynamics 365 Sales: create/edit the quote (or opportunity) → set the **Currency** lookup (a `transactioncurrency` record) and the **Price List**; the price list's currency must match.
  2. Dynamics 365 Sales: add products — the product lookup is filtered by the selected price list, and adding a product whose price list currency differs raises a pricing error.
  3. Dynamics 365 Sales: view totals — each money column is stored twice: transaction currency and `_Base` (organization base currency), with the read-only `ExchangeRate` column driving conversion.
  4. HubSpot: set the deal's **Currency** property; the quote's **Currency** label and formatting follow the deal. Account currencies are configured in Settings → **Manage currencies** and entered per-product and per-price-book.
  5. HubSpot: the quote editor's header module shows the currency; the *Totals* tab configures how discount is displayed (amount / percentage / both) in "the quote currency".
- **data_flow:** A `transactioncurrency` record (`ISOCurrencyCode`, `CurrencySymbol`, `CurrencyPrecision`, `ExchangeRate`) is chosen on the quote header (`transactioncurrencyid`) → line-item unit prices resolve from the `pricelevelproduct` row in that currency → totals (`totalamount`, `totallineitemamount`, `totaldiscountamount`, `totaltax`, `freightamount`) are computed in the transaction currency → the read-only `exchangerate` and `*_Base` columns (e.g. `totalamount_base`, `discountamount_base`) hold the converted base-currency view for reporting → on a wrong-currency combination, the platform refuses to price and sets `pricingerrorcode` (e.g. `34 Invalid Price Level Currency`, `38 Transaction currency is not set for the product price list item`).
- **data_sources:** Dataverse `transactioncurrency` table; `organization.basecurrencyid`; `pricelevel`, `pricelevelproduct`; quote/order/invoice `transactioncurrencyid` + `exchangerate` + `*_Base` columns. HubSpot deal/quote `Currency` property, account currency list, price book `Currencies` selection.
- **apis_hit:** Dynamics Web API: `GET /transactioncurrencies`, `POST /transactioncurrencies`, `PATCH /transactioncurrencies({transactioncurrencyid})`; the `RetrieveExchangeRate` message/event on the Currency table (`RetrieveExchangeRateRequest`, "Event: True"). `GET /transactioncurrencies(*transactioncurrencyid*)` for a single rate. HubSpot — `GET crm/properties/{version}/quotes` exposes `hs_currency`; `hs_currency` is a state-driven property populated on publish.
- **automations:** Currency/exchange-rate-driven recalculation on record open, create, update, and on product add/update/delete. HubSpot "quotes inherit the deal currency"; the quote's currency format is inherited from the deal record and "Changing the quote's locale settings won't update the currency."
- **features_tools:** Quote/order/invoice **Currency** and **Price List** fields; HubSpot quote **Header** module currency label; Totals tab **Total discount → Format** selector; **Manage currencies** settings page.
- **extensibility:** HubSpot — price books are single-currency ("Click the **Currencies** dropdown menu and select a currency"), so multi-currency is modelled as multiple price books; per-product price can be entered "in each of the currency fields". Dynamics — custom currency records (`CurrencyType: Custom`), plug-ins on pricing, and `exchangerate` is writable so a custom rate can be stamped.

The exchange rate is used to convert all money fields in the record from the local currency to the system's default currency." · `PricingErrorCode` option 38: "Transaction currency is not set for the product price list item"; option 34: "Invalid Price Level Currency". · `TransactionCurrency` table description: "Currency in which a financial transaction is carried out." · HubSpot: "Quotes created from deals match the associated deal's *Currency* property."
